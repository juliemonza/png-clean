# PNG Clean

Bulk PNG metadata removal and optional EXIF GPS tagging, processed entirely in your browser.

## Use

Select PNG files, optionally choose a Toronto/GTA preset or enter coordinates, then download the ZIP. Up to 200 files / 250 MB per batch.

## Privacy and limitations

Images never leave your device. Pixel data, dimensions and transparency are preserved. Colour profiles are removed, which can affect rendering. Animated PNGs are rejected. Location is applied to the whole batch; presets are approximate city centres. PNG EXIF GPS support varies between viewers.

## Hosting

Static HTML and ES modules with no dependencies or build step. GitHub Pages: deploy from main, root folder.

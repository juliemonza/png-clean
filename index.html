Existing EXIF, location, text, timestamps and other ancillary chunks are removed.

Presets are approximate city centres. Edit the coordinates for an exact location. The same location is applied to the whole batch.

PNG format, dimensions and pixel data stay intact. Transparency is preserved. Removing colour profiles can change how some viewers display colours. Animated PNGs are not supported.

Location is stored as EXIF GPS. Some websites and apps ignore or strip PNG geotags.
No account connection, image uploads or paid API. Files stay in this browser tab. Up to 200 images / 250 MB per batch.
